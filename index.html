One-time setup: deploy the scraper Worker

The dashboard needs a tiny Cloudflare Worker that renders each Maps page in a real headless browser (so the rating + reviews actually appear in the DOM) and returns clean JSON. Once it's deployed, "Refresh all" updates every pharmacy invisibly — no copy/paste, no manual entry.

  1. Open dash.cloudflare.com → Workers & Pages → Create application → Create Worker. Pick a name (e.g. pharm-scraper) and deploy the Hello World stub.
  2. Click your new Worker → Edit code → replace the contents with worker.js from this repo → Save and deploy.
  3. Back on the Worker overview: Settings → Bindings → Add → Browser Rendering. Set the variable name to BROWSER → Save.
  4. Make sure your account is on the Workers Paid plan ($5/month). Browser Rendering's free quota (10 min/day) is plenty for a few pharmacies refreshed weekly.
  5. Copy the deployed Worker URL (looks like https://pharm-scraper.your-name.workers.dev) and paste it below.
